# Trizone Power ☀️

A fully responsive, highly performant landing page and website built for a solar energy client. The platform is designed to educate homeowners and businesses on renewable energy while driving lead generation for solar installations.


## 🚀 Live Demo

You can view the live site preview at: **[trizonepower.netlify.app](https://netlify.app)**


## ✨ Features

- **Multi-Page Navigation:** Distinct structures for client marketing, including `index.html`, `about-us.html`, and `services.html`.
- **Lead Generation Contact Form:** Fully functional form integrated via [Formspree](https://formspree.io/) for direct submission handling.
- **Custom Pages:** Includes specialized `coming-soon.html` and `under-construct.html` pages.
- **Responsive Layout:** Tailored with optimized layout ratios.


## 🛠️ Tech Stack

- **Frontend:** CSS3, HTML5, JavaScript.
- **Form Handling:** [Formspree](https://formspree.io/).
- **Hosting:** Netlify.
